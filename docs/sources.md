# Répertoire des Sources Institutionnelles et Réglementaires

Les contenus de sécurité et doctrines intégrés dans NRBCOR proviennent exclusivement des portails officiels français suivants :

1. **Info.gouv.fr - Préparation aux situations d'urgence**
   - URL : `https://www.info.gouv.fr/risques/se-preparer-a-une-situation-durgence`
   - Usage : Directives sur le kit d'urgence 72h, autonomie hydrique et alimentaire du foyer.

2. **Ministère de l'Intérieur - Guide « Tous Responsables »**
   - URL : `https://www.interieur.gouv.fr/documentation/ressources/guide-tous-responsables.html`
   - Usage : Postures de sauvegarde et consignes d'alerte des populations.

3. **Direction Générale de la Sécurité Civile (DGSCGC) - Planification ORSEC**
   - URL : `https://www.securite-civile.interieur.gouv.fr/documentation/planification-orsec/planification-orsec.html`
   - Usage : Cadre général d'intervention et organisation des secours communaux.

4. **Secrétariat Général de la Défense et de la Sécurité Nationale (SGDSN)**
   - URL : `https://www.sgdsn.gouv.fr/nos-missions/anticiper-et-prevenir/ameliorer-les-dispositifs-de-protection-et-de-prevention`
   - Usage : Directives interministérielles NRBC-E (PIRATOX, BIOTOX, PIRANET).

5. **Autorité de Sûreté Nucléaire et de Radioprotection (ASNR / IRSN)**
   - URL : `https://www.asnr.fr/`
   - Usage : Doctrine de distribution et de posologie de l'iode stable, périmètres PPI (0-10km, 10-20km).

6. **Santé Publique France**
   - URL : `https://www.santepubliquefrance.fr/`
   - Usage : Recommandations d'hygiène, déshabillage et décontamination cutanée sans dispersion.

7. **Géorisques (Ministère de la Transition Écologique / BRGM)**
   - URL : `https://www.georisques.gouv.fr/`
   - Usage : Données publiques sur les installations classées SEVESO, PPRT et axes TMD.
